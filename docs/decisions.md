# mail-mcp-server — решения

Действующие решения пользователя и границы, которые изменение не может переступить без его
решения. Пересмотренные решения заменены итоговыми; история — в git. Как устроен сервер —
в [plan.md, раздел 3](plan.md#3-как-устроено) и `docs/*-agent.md`, состав версии — в
[plan.md, раздел 4](plan.md#4-версия-010), доработки после неё — в [backlog.md](backlog.md).

## 1. Чего не делаем без решения пользователя

- общих бюджетов, счётчиков и сроков разбора, отдельного процесса для разбора. Исключение —
  утверждённые лимиты раскрытия контейнеров (`docs/mime-agent.md`, решение Д10 в разделе 2):
  константы на одно письмо, без настроек и общего объекта бюджета;
- SQLite или другой базы рядом с индексом;
- состояний сверх `downloaded`/`converted`/`failed` с причиной;
- своего перевода HTML в текст и угадывания кодировок;
- запасного пути на случай отсутствия pandoc;
- автоматических повторов входа и записи в ящик;
- защит «на будущее», которых не требует задача.
