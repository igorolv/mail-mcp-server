# mail-mcp-server — доработки после 0.1.0

Возможные доработки, которые не входят в версию `0.1.0` (решение 2026-10-28). Состав текущей
версии — в [plan.md, раздел 4](plan.md#4-версия-010); отклонённые идеи с причинами — в
[decisions.md](decisions.md).

Статус: ⬜ не начато · 🔨 в работе. Размер: S — часы, M — бриф на одну сессию, L — несколько
брифов. Когда пользователь берёт пункт в версию, строка переносится в раздел 4 плана. Новая
идея — новая строка со следующим номером; номера не переиспользуются (следующий свободный — Д31).

| № | Доработка | Суть | Откуда | Размер | Статус |

| Д13 | Эмбеддинги и гибридный поиск | `multilingual-e5` через ONNX Runtime в JVM, объединение с BM25 (RRF). Отложено до реальных промахов поиска по смыслу: клиент поиска — агент, который сам переформулирует запрос. Цена: модель в памяти каждого процесса сервера, часы первичной обработки, своё разбиение на фрагменты, kNN без точного `total` и подсветки, качество оценивает только пользователь. Если брать — флаг, E5-small, отдельный режим `search`, BM25 по умолчанию | П12, RT-07, обсуждение 2026-10-27 | L | ⬜ |
| Д15 | Черновики за флагом | Инструмент `createDraft` (новое письмо или ответ с заголовками цепочки и локальными вложениями), включается флагом соединения, по умолчанию выключен. Общая сборка MIME; EWS — `CreateItem` с `MimeContent` и `SaveOnly`, IMAP — `APPEND` в «Черновики» с `\Draft` без `SELECT`. Без изменения и удаления черновиков; отправка не планируется (канал утечки при внедрении инструкций). Отдельное расширение проекта: меняет инвариант «только чтение» и добавляет вход в ящик по вызову агента. Проверить: признак `\Drafts` у Mail.ru, вид черновика в веб-интерфейсе, права пароля приложения на запись | цели MVP, обсуждение 2026-10-27 | L | ⬜ |
